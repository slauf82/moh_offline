# MOH v1.1.0 – Prozesstreue 2.0

## Highlights

- Kapitelstatus direkt in der linken Seitenleiste
- Live-Erkennung von offenen, begonnenen und vollständigen Kapiteln
- Prozentanzeige je Kapitel
- Sprungfunktion zum ersten offenen Feld
- Sichtbare Markierung fehlender Prozess-/Pflichtfelder
- Validierungsstatus direkt an Kapitelbuttons

## Neu

### Kapitelstatus

Jedes Kapitel wird automatisch bewertet:

- 🟢 vollständig
- 🟡 begonnen
- 🔴 offen

### Offene Felder schneller finden

Über „Zum ersten offenen Feld“ springt MOH automatisch zum nächsten nicht ausgefüllten Prozessfeld.

### Prozesstreue 2.0

Die bisherige Prozesstreue wurde um eine kapitelbezogene Qualitätsanzeige erweitert.
