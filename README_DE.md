# MOH Offline

**Medizinisches Workflow- und Dokumentationssystem**

🇬🇧 **English:** [README.md](README.md)

## Überblick

MOH Offline ist die moderne Standalone-Version eines langjährig
eingesetzten medizinischen Dokumentations- und Untersuchungssystems.

Das Projekt ersetzt die ursprüngliche Serverumgebung, erhält die
bestehende Fachlogik und erweitert sie um moderne, prozessorientierte
Funktionen.

## Funktionen

-   Offline-Betrieb
-   Medizinische Dokumentation
-   Regelbasierte Prozessführung
-   Untersuchungs-Workflows
-   Automatische Scoreberechnung
-   Kapitelstatus
-   Prozesstreueprüfung
-   Moderne Weboberfläche
-   Import, Export und Reports
-   Langfristige Wartbarkeit

## Prozesstreue

Die regelbasierte Prozesslogik bewertet nicht nur die Vollständigkeit
der Daten, sondern unterstützt medizinisch sinnvolle Abläufe.

Beispiele:

-   Folgetermine können von vorherigen Untersuchungen abhängen.
-   Workflowstatus wird übersichtlich dargestellt.
-   Automatisch berechnete Werte beeinflussen die Dokumentationsprüfung
    nicht.

## Technologie

-   Java
-   Spring Boot
-   React
-   TypeScript
-   Vite

## Ziel

Bewährte medizinische Arbeitsabläufe erhalten und gleichzeitig eine
moderne, offlinefähige und langfristig wartbare Anwendung schaffen.
